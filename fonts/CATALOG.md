# Font catalog

All fonts are open source (SIL Open Font License; license file next to each). Each family has 400 and 700. Most also have a 400 italic. Setup installs them on this PC, so PowerPoint shows them.

| Family | Kind | Italic | Character |
|---|---|---|---|
| Inter | Sans | yes | Neutral, very legible UI sans. Safe, but plain. |
| IBM Plex Sans | Sans | yes | Engineered, slightly technical, businesslike warmth. |
| DM Sans | Sans | yes | Geometric, friendly, low contrast. Good at large sizes. |
| Space Grotesk | Sans | no | Quirky geometric grotesk with character. Best for headlines. |
| Manrope | Sans | no | Modern, rounded geometric. Clean and contemporary. |
| Source Sans 3 | Sans | yes | Humanist, calm, readable body text. |
| Source Serif 4 | Serif | yes | Editorial serif, sturdy at large sizes. |
| IBM Plex Serif | Serif | yes | Technical serif that pairs natively with Plex Sans and Plex Mono. |
| Fraunces | Serif | yes | Soft, expressive display serif with personality. Headlines only. |
| Roboto Mono | Mono | no | Plain, even mono. |
| IBM Plex Mono | Mono | yes | Characterful mono with a typewriter feel. |
| JetBrains Mono | Mono | yes | Code mono, tall and clear. |

Pairing ideas (not rules): a serif headline over a sans body reads editorial; one sans for everything plus a mono for labels reads technical; a display sans headline over a humanist body reads modern and friendly.
