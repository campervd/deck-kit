# Story

This is a six-minute invitation to try the deck kit with clear expectations. It opens with the problem behind it, makes the promise tangible through inputs and outputs, shows the build loop and its quality rails, is candid about the Windows sandbox limitation and bridge, then closes with a specific request.

## Slide 1

- Claim: Decks from notes makes a better starting point for a talk.
- Shape: Opening.
- Form: Cover, with the title as the dominant object and two restrained descriptor chips.
- Emphasis: The title.
- Background: Dark.
